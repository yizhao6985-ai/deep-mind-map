## 1. 设计语言一句话

**软石墨灰阶 + 墨条选中 + 浮岛工具，不做胶囊、不做彩光、不做第二套壳。**

气质：本地生产力工具；安静、密实、可扫读。品牌感来自 Manrope 字重与近黑墨色，不来自渐变或彩色强调。

---

## 2. 产品形态（先定形，再定皮）

本产品是**本地工作区应用**，不是营销落地页，也不是仪表盘。

### 2.1 单一工作区骨架

图库与编辑合并为同一壳；同步属于设置维度，不出现在工作区工具栏。

```
┌─ 220px 侧栏（可拖宽）─┬─ 主区 ──────────────────────────────────┐
│ Brand（轨高 48）       │ 轨 A 48px：Tabs | 保存状态 | 设置入口     │
│ MAPS + 新建            ├──────────────────────────────────────────┤
│ 思维导图树列表             │ Canvas / 空状态                          │
│ （点开进 Tab）         │   └ 左上撤销 · 左下缩放 · 右下 AI 岛     │
│ 设置（底栏）           │                                          │
└───────────────────────┴──────────────────────────────────────────┘
```

规则：

1. **左侧管文档**：列表、新建思维导图/文件夹、重命名、删除；设置入口在侧栏底部（顶栏亦可打开设置）。
2. **主区管编辑**：Tab 切换已打开思维导图；画布浮岛：左上撤销/重做、左下缩放、右下 AI（Ask / Agent）。
3. **同步另维**：GitHub 推送/拉取只在「设置 → 同步」，不与编辑混排。
4. **无 MapStyle 切换**：节点外观固定 classic；文件可存 `mapStyle`，无工具条入口，无 `map-style-*` 运行时类。
5. **空状态**：未打开思维导图时主区提示选择或新建，侧栏仍可用。
6. **导入入口**：当前无侧栏「导入」；待产品入口交付后再补。

## 3. 设计原则

1. **对齐优先**：同一轨内控件垂直居中；壳层左右边距统一为 `--pad-x`（16）。
2. **尺寸离散**：控件高度只允许 `28 / 32 / 36`；壳层轨高 `40 / 48`。禁止随意出现 30、34、44、56。
3. **间距 4 的倍数**：布局间距用 `--s1`…`--s7`（4–48）。禁止布局用 6、10、14、18、22；**分割线 / 1–2px 描边 / 墨条缩进裁剪除外**。
4. **少色**：默认近黑 / 灰阶；危险色仅用于删除；成功色仅用于「已保存」等正向状态。
5. **少装饰**：无胶囊标签墙、无彩色 AI 光晕、无卡片阴影堆叠；列表与壳层无阴影。
6. **不用胶囊**：按钮、分段、标签、导航项禁止 `border-radius: 999px` 拉成长药丸。选中用**底边墨条**或**左侧墨条**。等宽等高的小圆点 / 圆形图标钮（节点 chrome、步骤标记）除外。

### 3.1 禁止

- 紫/靛蓝渐变主色；暖奶油底 + 陶土强调
- Inter / Roboto / Arial 作为品牌字体
- 将同步（推送/拉取）放进编辑器或侧栏主操作区
- 编辑顶栏塞入 MapStyle / 思维导图外观分段（应用浅色/深色仅在设置）
- 独立「图库首页」与编辑器两套壳来回跳转
- 胶囊形分段轨（iOS pill track）、胶囊标签堆、圆角满 `999px` 的宽按钮 / Chip

### 4.2 字体

| Token | 字体 | 用途 |
|------|------|------|
| `--font` | Manrope | UI 与品牌 |
| `--font-mono` | IBM Plex Mono | 路径、URL、代码 |

| 层级 | 大小 / 行高 / 字重 | 用途 |
|------|-------------------|------|
| Display | 20 / 28 / 650 | 引导页标题 |
| Title | 15–18 / ~24 / 650 | 侧栏标题、设置页眉 |
| Body | 13 / 20 / 500–550 | 列表、按钮、消息 |
| Caption | 12 / 16 / 450–550 | 次要说明、Tab 字 |
| Micro | 11 / 16 / 500–600 | 保存状态、侧栏分组、模式分段 |
| Nano | 10 / — / 650–700 | AI 品牌徽标、折叠计数（仅此二处） |

字距：标题 `-0.03em`，正文 `-0.01em`。侧栏分组标签可 `0.06em` + uppercase。

### 4.3 控件尺寸（硬约束）

| 名称 | 值 |
|------|-----|
| `--control-sm` | 28px（纯图标按钮） |
| `--control-md` | 32px（带文字按钮 / 侧栏项 / Tab） |
| `--control-lg` | 36px（表单主按钮） |
| `--chrome-a` | 48px（侧栏品牌轨 / 编辑轨 A） |
| `--chrome-b` | 40px（AI 头栏） |
| `--rail` | 220px（侧栏默认宽，可拖） |
| `--pad-x` | 16px（壳层左右内边距） |
| `--panel-ai` | 360px（AI 浮岛宽） |

图标默认 16px，描边 1.5；节点 chrome 内图标可 11–12。

### 4.4 间距与圆角

| Token | 值 |
|-------|-----|
| `--s1`…`--s7` | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| `--r-sm` / `--r-md` / `--r-lg` | 6 / 8 / 10 |

控件圆角不得超过 `--r-lg`；禁止用 `999px` / `50%` 做宽高不等的「胶囊」。  
根节点圆角特例：`14px`（大于 `--r-lg`，仅根主题）。  
阴影：仅 Modal / Menu / 画布浮岛使用 `--shadow-menu` 或 `--shadow-float`；列表与壳层无阴影。

### 4.5 动效

| 名称 | 规格 | 用途 |
|------|------|------|
| `toast-in` | 180ms，opacity + translateY(-8px) | Toast |
| `ai-pulse` | 1.2s，opacity 0.55↔1 | AI 忙碌徽标 |
| `agent-caret` / `agent-dot` / `agent-step-pulse` | 微交互 | 仅 AI 面板 |

交互态用 `120ms ease`（`--ease`）。禁止整页装饰动画、彩色光晕脉冲。

## 5. 组件规格

### 5.1 IconButton

- 默认：`28×28`，透明底，hover `--hover`
- 带字：`height 32`，左右 padding 12
- Primary：墨底 + `--on-ink`
- Danger：仅文字/图标变红，hover `--danger-soft`
- Active：墨底（用于 AI 面板开关等）

### 5.2 Library 树

```
每行 32px：[depth×12px 缩进][twist 16][title flex][actions?]
```

- 缩进：`padding-left: 8px + depth × 12px`
- 全宽 hover / 选中；选中配方统一为 **左侧 2px 墨条 + `--hover` 底**（与设置导航一致；墨条上下各缩 6px）
- 操作按钮占位常在，`opacity` 显隐，避免布局跳动
- 思维导图不显示相对时间

### 5.3 Tab

- 高度 `--control-md`（32），最大宽 160；超出省略
- Active：底边 2px 墨条；Inactive：透明；无胶囊/白底卡片
- Dirty：小方点；hover 时与关闭钮互斥显示

### 5.4 设置

- 布局：左侧分类导航（通用 / AI / 同步 / 关于）+ 右侧内容；嵌在工作区壳内（`workspace-settings`），**不是**独立 56px 顶栏页
- 导航项：全宽、无圆角卡片；选中配方与侧栏树相同（左侧 2px 墨条 + `--hover` 底）
- 主题分段：底边墨条分段，禁止胶囊轨
- 内容块 `settings-block`：`--surface` + 细边框 + `--r-lg`

### 5.5 画布浮岛

- **左上**：撤销 / 重做
- **左下**：缩小 · 缩放百分比（点按重置 100%）· 放大 · 适应画布
- **右下 AI**：入口小岛；展开后贴右缘、上下边距 16，高度随画布撑满
- 样式：`--surface`、细边框、圆角 `--r-md`/`--r-lg`、`--shadow-menu`，外边距 16
- AI 头栏高 `--chrome-b`（40）：品牌徽标、对话切换、新对话/删除/关闭
- 消息区 `--bg`；工具步骤为时间线列表，非彩色光晕
- Ask / Agent：底边墨条分段（与设置主题一致）
- 打开/关闭不改变画布栅格宽度

### 5.6 节点与分支（对标 XMind 右向图）

- **连接锚点**：入/出边为 **1×1 不可见 handle**（不绘关节圆点）；操作钮在节点外侧轨道，不与连线端点抢位
- **根（中心主题）**：墨底 + `--on-ink`，padding 12×22，圆角 14，字号 15 / 650；轻投影
- **一级主题**：`--surface` + 1.5px `--line-node` 描边，padding 8×14，圆角 8，字号 13 / 600
- **更深层级**：描边变浅、padding 8×12、字号 12、字色 `--ink-secondary`
- **选中**：2–3px 焦点环（`--ring` / `--ring-soft`）；关联分支用 `--branch-hot`
- **分支连线**：圆角肘线，`--branch` / 1.6px，线帽 round
- **添加子节点**：悬停/选中时出现在节点右侧外侧（约 8px 间隙）
- **展开/收起**：有子节点时在节点左侧外侧；折叠态常显子树数量
- **添加同级**：悬停/选中时在节点底边外侧（根不显示）
- **快捷键**：Tab 子节点 · Enter 兄弟 · F2 / 双击编辑 · Delete 删除 · ⌘Z 撤销

## 7. 验收清单（防「歪扭」）

- [ ] 侧栏宽默认 220（可拖宽）；轨 A 高 48
- [ ] 轨 A 左右 padding 均为 16（含平台 overlay inset）
- [ ] 图标按钮高度仅为 28 或 32；表单主按钮 36
- [ ] 工作区无同步入口；同步仅在设置
- [ ] 无 MapStyle 切换入口；无生效的 `map-style-*` 类
- [ ] 无琥珀色 / 紫色品牌色块；成功绿仅用于状态
- [ ] Ask / Agent 与主题分段均为底边墨条，非胶囊轨
- [ ] 分支色走 `--branch` / `--branch-hot`，深浅主题一致
- [ ] 侧栏树与设置导航选中均为墨条 + `--hover`
- [ ] 一级节点描边走 `--line-node`
- [ ] 布局间距无半拍值（6 / 10 / 14 / 18 / 22）；节点 chrome 圆钮除外
